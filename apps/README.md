# Apps

Purpose: secondary runnable application surfaces for this repository.

Owner: `sdkwork-api-cloud-gateway` maintainers.

Allowed content: future app surface roots, demos promoted to runnable apps, or deployable app compositions that need their own `sdkwork.app.config.json`.

Forbidden content: Rust crates, generated SDK output, runtime user state, local secrets, and source config templates that belong in `configs/`.

Related specs: `../sdkwork-specs/APPLICATION_SPEC.md`, `../sdkwork-specs/APP_MANIFEST_SPEC.md`, and `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.

Verification: this is currently a placeholder because the repository root is the primary application root.
