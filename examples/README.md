# Examples

Purpose: runnable examples and copyable integration examples for SDKWork API Gateway consumers.

Owner: `sdkwork-api-cloud-gateway` maintainers.

Allowed content: sample commands, safe example configs, SDK/API usage examples, and integration fixtures.

Forbidden content: live credentials, generated SDK transport output, runtime state, and production config.

Related specs: `../sdkwork-specs/DOCUMENTATION_SPEC.md`, `../sdkwork-specs/CONFIG_SPEC.md`, and `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.

Verification: examples must be covered by a documented command before they are treated as release evidence.
